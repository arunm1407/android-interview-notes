## Interview Day — Pocket Checklist

**Coding round**
- [ ] Repeat problem in own words
- [ ] Clarify constraints + edge cases
- [ ] State brute force + Big-O
- [ ] Name pattern before coding
- [ ] Talk while typing
- [ ] Dry-run example
- [ ] Test: empty, single, duplicates, max size
- [ ] State final time + space complexity

**System design round**
- [ ] Functional + non-functional requirements (5 min)
- [ ] High-level diagram (5 min)
- [ ] API + data model (10 min)
- [ ] Offline / sync / cache strategy (10 min)
- [ ] Failure modes + monitoring (5 min)
- [ ] Trade-offs summary (5 min)

**Behavioral round**
- [ ] STAR format — Situation 20%, Action 60%, Result 20%
- [ ] Include YOUR specific contribution
- [ ] End with measurable outcome
